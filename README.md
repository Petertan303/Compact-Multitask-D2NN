# Spatial parameter sharing in diffractive neural networks

Source code for a numerical study of a diffractive deep neural network (D2NN) in which four
classification tasks share phase pixels through partially overlapping sub-apertures. All results
are numerical simulations; there is no experimental data in this repository.

## Optical model

- Phase canvas: 300 x 300 pixels, pitch `DX = 8 um`, wavelength 1550 nm.
- Propagation between layers: angular spectrum method over `DISTANCE = 8 mm`.
- Device: three phase-only layers, one phase value per pixel (no basis expansion).
- Sub-apertures: quarter disks of radius 212 px centred on the four canvas corners. Neighbouring
  disks overlap, so the four tasks share a band of 51,920 pixels per layer out of 90,000.
- Detection: differential detection, one pair of positive and negative lobes per output class.

| Region | Dataset |
| --- | --- |
| NW | MNIST |
| NE | Fashion-MNIST |
| SW | EMNIST letters, labels A to J |
| SE | Shapes (10 synthetic classes generated by `d2nn/shapes.py`) |

## Layout

| File | Content |
| --- | --- |
| `d2nn/config.py` | geometry, wavelength, distances, region/task table |
| `d2nn/optics.py` | angular-spectrum propagator, image placement on the canvas |
| `d2nn/layers.py` | pixel-wise phase layer, quarter-disk aperture mask |
| `d2nn/losses.py` | target loss with background and cross-region energy terms |
| `d2nn/readout.py` | differential detector masks, balanced test subsets |
| `d2nn/data.py` | dataset loading, including `SyntheticShapes` |
| `d2nn/shapes.py` | generator for the Shapes dataset |
| `d2nn/training.py` | seeding, batch sampling, differential gallery |
| `d2nn/stage_utils.py` | isolated sub-network used in the first stage |
| `d2nn/stage1_centroid.py` | centroid of each quarter disk, used as input position |
| `d2nn/stage2_net.py` | shared three-layer device and the phase-averaging merge |
| `train_stage1.py` | first stage: four isolated sub-networks |
| `merge_init.py` | pixel-wise phase averaging of the four sub-networks |
| `train_stage2.py` | second stage: joint fine-tuning of the merged device |
| `train_stage2_concurrent.py` | second stage with several sub-apertures illuminated at once |
| `control_tiled_stage1.py`, `control_tiled_stage2.py`, `control_tiled_eval.py`, `control_tiled_lib.py` | equal-budget control: four non-overlapping 150 x 150 squares |
| `eval_accuracy.py` | per-channel accuracy of one or more devices |
| `eval_concurrent.py` | accuracy under one to four simultaneously illuminated channels |
| `eval_crosstalk.py` | energy in the target region against energy elsewhere |
| `eval_false_alarm.py` | response of each channel to empty and misplaced inputs |
| `eval_aperture_budget.py` | pixel budget of the sharing layout and of the controls |
| `eval_dataset_stats.py` | class counts of the four datasets as loaded |

## Setup

```
pip install -r requirements.txt
python -m d2nn.shapes          # writes ./data/synthetic_shapes_train and _test
```

MNIST, Fashion-MNIST and EMNIST are downloaded to `./data` on first use. A CUDA GPU is strongly
recommended: one first-stage sub-network takes a few minutes and a full second-stage fine-tuning
run takes on the order of an hour.

## Training

```
python train_stage1.py --tag v2                       # four quarter-disk sub-networks
python merge_init.py --tag v2                         # phase-averaged initial device
python train_stage2.py --init merged --tag v2         # joint fine-tuning, curriculum on
```

Controls for the same command line: `--init random` starts the second stage from random phases;
`--no-curriculum` keeps the four task weights fixed; `control_tiled_stage1.py` and
`control_tiled_stage2.py` build the non-overlapping equal-budget device.

`train_stage2_concurrent.py --arm concurrent` fine-tunes with a random number of channels lit at
each step, and `--arm gate` adds the presence margin term. Weights are written to `checkpoints/`,
run summaries to `results/`.

## Evaluation

```
python eval_accuracy.py --ckpt checkpoints/<device>.pth
python eval_concurrent.py --ckpt checkpoints/<device>.pth
python eval_crosstalk.py --ckpt checkpoints/<device>.pth
python eval_false_alarm.py --ckpt checkpoints/<device>.pth
python eval_aperture_budget.py
```

Pass `--geom tile150` to `eval_concurrent.py` and `eval_false_alarm.py` for the tiled control.
Accuracies are reported on balanced test subsets (`--n-per-class`, default 100 per class) and use
differential detection.

## Reproducibility

Every training script takes `--seed`; the first stage also takes `--regions`, `--layers` and
`--epochs`. Splits are the published train/test splits of MNIST, Fashion-MNIST and EMNIST, and
6000/1000 generated images per class for Shapes. Reported means are averaged over the four
channels.
